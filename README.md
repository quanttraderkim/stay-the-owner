# stay-the-owner

에이전트를 도구로 쓰되, 결과의 주인은 내가 된다.
Use agents as tools. Stay the owner of the outcome.

AI 에이전트에게 일을 많이 맡길수록 "이걸 내가 이해하고 책임질 수 있나?"가 흐려진다. 이 레포는 그걸 지키기 위한 원칙, 스킬, 루틴 모음이다. 어떤 에이전트(Claude Code, Cursor, Grok Bot 등)에도 붙여 쓸 수 있다.

출발점 / Inspired by: Addy Osmani, ["Critical thinking when agents do the work"](https://x.com/addyosmani/status/2117512471930167377)

## 구성 / Contents
- [`PRINCIPLES.md`](PRINCIPLES.md): 모든 에이전트가 따르는 작업 원칙. 에이전트의 시스템 프롬프트나 공유 메모리에 넣어 쓴다.
- [`skills/deep-review/SKILL.md`](skills/deep-review/SKILL.md): 중요한 결과를 깊게 검토하고 퀴즈로 이해도를 확인하는 스킬.
- [`routines/weekly-check.md`](routines/weekly-check.md): 매주 한 번 에이전트들이 한 일을 훑어 "확인 없이 넘긴 결정"을 짚어 주는 루틴.

## 쓰는 법 / How to use
1. `PRINCIPLES.md`를 에이전트 규칙(AGENTS.md, CLAUDE.md, 시스템 프롬프트, 공유 메모리)에 붙인다.
2. 배포·병합·돈이 걸린 결정 전에 deep-review 스킬을 돌린다.
3. 주간 점검을 스케줄러에 걸어 둔다.
